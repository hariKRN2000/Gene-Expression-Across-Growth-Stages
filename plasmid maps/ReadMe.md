### Key to plasmid maps: 
All the plasmids have ColE1 high copy backbone. <br> <br> 
Different constructs in each plasmid: <br> <br> <br>
(A) pCH-M052.gb : sfYFP-ssrA gene expression cassette <br> <br>
(B) pCH-M052.gb : sfYFP-aav gene expression cassette <br> <br>
(C) pCH-M095.gb : sfYFP gene expression cassette (untagged system) <br> <br>
(D) pCH-M037.gb : empty backbone (negative control) <br> <br> <br>

All the constructs (A, B, C) use the same promoter (P5d), RBS (U1d) and terminator (T1m). You can refer to the GenBank files for more details.
